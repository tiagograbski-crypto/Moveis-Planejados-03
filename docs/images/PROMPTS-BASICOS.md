# Prompts básicos — Tendência (todas as imagens)

Use o **prompt negativo** em todas. Paleta: marrom `#3E3129`, terracota `#C49A6C`, creme `#E8E5E1`.

**Prompt negativo (sempre):**
```
texto, logo, marca, watermark, cores frias, neon, azul, móvel barato, bagunça, 
desfoque, rostos, cartoon, render falso, texto de cidade
```

---

## 01 · HERO — `01-hero/hero-capa-marrom.webp`
**Desktop:** capa widescreen, card de texto à esquerda.  
**Mobile:** mesma foto em tela cheia atrás do card — **centro da imagem limpo e bonito** (não cortar o melhor pedaço nas bordas).

**Prompt:**
```
Cozinha e living integrados de luxo, armários marrom noce escuro e creme, 
luz natural quente lateral, marcenaria planejada alto padrão, foto editorial 
realista, tons marrons quentes, sem pessoas
```
**Proporção:** 3:2 · 2400×1600

## Resumo mobile (estratégia)

| Imagem | No celular, ela precisa… |
|---|---|
| Hero | Funcionar em tela cheia; centro forte (card cobre parte inferior) |
| Solução | Detalhe macro que “vende” qualidade num retângulo alto |
| Anatomia fundo | Sumir atrás do overlay — só textura escura |
| Anatomia ×4 | Textura/assunto claro no carrossel 82vw com scrim |
| Execução cozinha | Primeiro impacto do portfólio — ambiente completo |
| Execuções 2 e 3 | Um elemento hero each (ripado / closet LED) |
| Social OG | Ler bem em thumbnail pequeno |
